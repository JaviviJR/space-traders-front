## Project rules for this phase

- A question follows `doc/workflow.md` → Options, if that section exists,
  before the table above when one of its options contradicts or relies on a
  rule in `AGENTS.md`, a `doc/*.md` or a closed decision (e.g. the spec's
  Assumptions), or when it changes something hard to undo: an external
  contract, the flow the user sees, or state that persists. Other questions
  keep the format above. The table, `**Recommended:**`, answering by letter,
  the limit of 5 questions and writing `spec.md` after each answer stay as
  described above.
- When a project rule makes you skip or change a step above, say so in one
  line, naming the step and the rule.
