## Project rules for this phase

- Features are implemented with `/feature-session`, one session per row of
  the "Sessions" table in `tasks.md`; those sessions count as the
  `/speckit-implement` run this command requires.
- If you append a `## Phase N: Convergence`, end that same section with its
  own `### Sessions` table, numbered after the last session and following the
  template's columns (including "Command") and its grouping and "Close"
  rules, instead of adding rows to the existing table. The handoff is
  `/feature-session`, never `/speckit-implement`.
- When a project rule makes you skip or change a step above, say so in one
  line, naming the step and the rule.
